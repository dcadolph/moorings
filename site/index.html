Works with what you already use

Your displays. Your habits.

Moorings starts with Rectangle's shortcuts, so your hands already know them. Every action is also a moorings:// link, so anything that opens a URL can run it.

Snap by dragging

Drag to an edge. Let go.

Drag a window to an edge or a corner and a footprint shows where it will land. Let go and it snaps. Hold Option while dropping on an ultrawide strip and the app is anchored there.

Workspaces

Save a layout. Get it back.

Save where every window sits on every display under a name, then recall it from the menu, a shortcut or a link. Tie one to a set of displays and plugging into that desk recalls it.

On an ultrawide

Pin the edges. Work in the middle.

Anchor up to four apps to the sides of the screen, a top and a bottom slot on each side. Everything else stays in the open middle, the channel. Nothing is anchored until you pick an app, so a first start moves no window.

Green button

Lift Slack over the channel

Click an anchored app's green button to lift it over the channel, and again to lower it. A free window's green button fills the channel.

Let it go

Drag an anchored window away and Moorings lets it go. Cast off this window lets one window cover the strips until it closes.

Every theme is a color set checked for contrast. Pick one and this whole page changes, including the screen above. The app uses the same names.

Get moorings

It moves windows. Nothing else.

Moorings needs Accessibility access to move windows. No account, no server, no analytics. Once a day it checks GitHub for a new release and offers it in the menu. Nothing installs on its own.
